HTML 태그의 특징 1. 시작 태그와 종료 태그가 모두 있는 경우(종료 태그가 생략되면 오류날수도) 2. 시작 태그만 있는 경우 3. 태그와 속성은 대소문자 구분이x 4. 속성 값에 불필요한 공백 문자, HTML 표준에 어긋남 속성의 종류 class 클래스 이름 id 아이디

문단 h 태그 위 둘의 차이점은 딱 하나에만 사용하는지(id), 여러개에 동시에 사용할 수 있는지(class) p는 문단으로 가리키고 id는 이름으로 가리킴(딱 하나만 해당) h는 태그고 id는 속성임, h태그는 제목이고 id는 그 요소의 고유한 이름 인라인 css 스타일 추가 정보, 툴팁으로 표시 href 링크의 목적지를 지정 +src, alt 등등
